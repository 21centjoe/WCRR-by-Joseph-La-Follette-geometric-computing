How this works

Your file is split into pieces, one per vertex of a real 60-vertex fullerene graph (the same shape as a soccer ball / Buckminsterfullerene molecule). The 32 faces each store a backup value, so losing a piece can often be repaired from its neighbors — verified by checksum, never assumed.

What's real in this build

AES-256-GCM encryption, gzip compression, fullerene face-parity self-healing, real PNG steganography (confirmed openable by an independent image library, not just this tool), and a real ZIP writer (confirmed against Python's own zip library). Every one of these was tested with an actual pass/fail check before being included — not assumed to work.

What's intentionally not included

No sketchbook/drawing editor in this build — narrowed out earlier to keep the tool focused on storage and self-healing. No true forensic-certainty tamper detection (doesn't exist as a solved problem — ELA is the honest, scoped version). No claims about speed, computation, or capabilities beyond real file storage.
